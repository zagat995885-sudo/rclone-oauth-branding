Privacy policy — rclone-drive

Last updated: 2026-11-17.

rclone-drive is a personal, single-user desktop OAuth client used by its owner (zagat995885@gmail.com) with the open-source tool rclone on the owner's own computer.

Data accessed

The app requests access to the owner's own Google Drive files and file metadata, only when the owner explicitly runs rclone commands. OAuth tokens are stored locally in the owner's rclone configuration file on the owner's machine.

Data collection and sharing

  • No personal data is collected, stored or processed by any server of this app: the app has no backend.
  • No data is sold, shared or disclosed to third parties.
  • File contents transit directly between the owner's computer and Google's Drive API over TLS.
  • No analytics, advertising or tracking technologies are used.

Retention and deletion

Local copies created by rclone remain under the owner's control and can be deleted at any time. OAuth access can be revoked at any time in the owner's Google Account security settings or by deleting the rclone remote.
